# Projets Automatisme Industriel — Ladder / API Mitsubishi FX

Série de 4 projets réalisés en TP d'automatisme industriel (EE452)  
à l'IGEE, Université M'Hamed Bougara de Boumerdes (2024/2025).  
Environnement : **GX Works 2/3**, API **Mitsubishi FX**, Mini-PLC Trainer.

## Projets

| # | Projet | Concepts clés |
|---|---|---|
| 01 | Feux de carrefour avec passage piéton | Timers, séquence cyclique, MC/MCR |
| 02 | Parking automatique avec barrière | Compteurs UP/DOWN, gestion de limite |
| 03 | Machine à laver | Séquence multi-étapes, capteurs de niveau |
| 04 | Alarme anti-intrusion | Timers, relais spéciaux M8013, MC/MCR |
